# FFmpeg工具目录

请将以下三个文件放在这个文件夹中：

- ffmpeg.exe
- ffprobe.exe
- ffplay.exe

## 如何获取这些文件

### 方法1：从FFmpeg官网下载
1. 访问：https://github.com/BtbN/FFmpeg-Builds/releases
2. 下载：ffmpeg-master-latest-win64-gpl.zip
3. 解压后，找到bin文件夹
4. 将bin文件夹中的三个exe文件复制到这里

### 方法2：使用国内镜像
- 下载地址：https://www.gyan.dev/ffmpeg/builds/ffmpeg-git-essentials.7z

## 文件说明

- **ffmpeg.exe** - 主要的视频处理工具，用于裁剪去水印
- **ffprobe.exe** - 用于获取视频信息（尺寸、时长等）
- **ffplay.exe** - 简单的视频播放器（可选，不需要也能用）
